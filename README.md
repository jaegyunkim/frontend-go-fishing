바다낚시 출조 AI 에이전트 **어디물어**의 모바일 화면입니다. GitHub Pages 로 배포됩니다.

**👉 https://jaegyunkim.github.io/frontend-go-fishing/**

- 대화: 출발지·날짜·지역을 말하면 대표 포인트 → 바다 상태 → 추천 TOP3 → 상세 브리핑
- 브리핑: 바다낚시지수·물때·파고·풍속·수온·특보·조석·일출몰 / 포인트 정보 / 네이버 지도 / 고속도로·일반도로 경로와 통행료·유류비 / 실시간 돌발 / 주변 2km(낚시점·편의점·주차·화장실·음식·약국·병원·숙박·주유소) / 가장 가까운 응급실 / 안전 체크 / 출처·수집 상태
- 로그인: 관리자가 발급한 계정으로 로그인, **1회 10분**(계정별 조정) 후 자동 로그아웃, 남은 시간 타이머·1분 전 경고, 첫 로그인 비밀번호 변경
- 한도 표시: 이번 세션·오늘 질문 수, 한도 초과 시 안내
- 관리자 화면 `admin.html`: 계정 발급·한도·중지·비밀번호 초기화, 접속 세션 강제 종료, 일별 사용량(질문·AI 토큰·외부 API 호출), 대화 로그, 로그인·작업 기록
- PWA: 홈 화면에 추가 가능

## 인증 방식
- 토큰은 `sessionStorage`(탭을 닫으면 삭제)에만 두고 `Authorization: Bearer` 헤더로 보냅니다. Pages 와 백엔드 도메인이 달라 쿠키를 쓰지 않습니다.
- 서버가 만료를 최종 판단합니다(만료 토큰은 401). 화면은 서버가 알려 준 남은 시간으로 타이머를 맞춥니다.
- 서버가 로그인 없이 동작하면(`AUTH_MODE=off`, 로컬 개발) 로그인 화면 없이 바로 대화합니다.

## 구조
이 저장소는 **정적 파일만** 있습니다(HTML/CSS/JS, 빌드 없음): `index.html`·`app.js`(대화), `auth.js`(로그인 공용), `admin.html`·`admin.js`(관리자). API 키·주소 같은 비밀은 없습니다.
데이터는 비공개 백엔드(`backend-go-fishing`, 맥미니 예정)가 공공데이터포털·기상청·국립해양조사원·카카오·네이버·오피넷·ITS·Notion 을 조회해 돌려줍니다.

## 백엔드 연결
1. 백엔드를 HTTPS 로 공개(Cloudflare Tunnel 등)
2. `config.js` 의 `window.GOFISHING_API` 에 주소 입력 후 커밋 — 또는 화면 ⚙︎ 설정 / `?api=https://…` 쿼리
3. 같은 컴퓨터에서 백엔드를 켰다면 `http://localhost:8787` 도 동작(Chrome 의 사설망 접근 허용 헤더 포함)

## 프런트 오류 보고 → 백엔드 → Slack
- `telemetry.js`는 **classic script**로 모든 HTML에서 `config.js` 다음, 첫 module 앞에 로드합니다. 초기 모듈 실행/로드 오류(`error`, capture)와 `unhandledrejection`을 수집합니다.
- `auth.js`의 `api()`는 network/timeout, HTTP 5xx, JSON 파싱 실패를 보고합니다. 정상 응답/일반 4xx는 보고하지 않습니다. 기존 예외·인증 처리와 JSON 실패 시 `{}` 반환 동작은 유지합니다.
- 수집기는 공개 `POST <실제 API base>/v1/client-errors`에 `{kind,message,stack,page}`만 보냅니다. 최대 길이는 각각 40/1000/2000/200자입니다. 초기 query → 저장된 주소 → config → localhost 순서와 설정 변경/예비 서버 전환을 반영합니다. `report(kind, message, stack, actualBase)`로 요청 당시 주소를 명시할 수 있고, `setApiBase()`로 이후 전역 오류 목적지를 변경합니다.
- 인증 헤더·쿠키·리퍼러·요청/응답 본문·사용자 객체·폼 값은 보내지 않습니다. API 오류 문구는 고정 문자열/HTTP 상태 코드만 사용합니다. 전역 오류 문자열에서는 URL, query/hash, 비밀번호/토큰/키 관련 문구, Bearer/JWT, 이메일, 인용문과 긴 토큰 형태를 제거합니다. stack은 알려진 앱 JS의 파일명·줄·열만, page는 알려진 HTML 파일명만 남깁니다. **임의 오류 문자열의 개인정보를 완벽히 판별할 수는 없으므로 애플리케이션에서 사용자 입력·비밀번호·토큰을 Error 메시지에 넣지 마세요.**
- 동일 정제 payload는 60초 동안 중복 제거, 탭의 페이지 로드당 최대 30회, 60초당 최대 5회 전송 시도합니다. 실패도 횟수에 포함합니다. 메모리 내 제한이라 새로고침하면 초기화되며, 서버의 Origin 허용 목록과 rate limit을 대체하지 않습니다.
- 전송은 `api()`가 아닌 별도 `fetch`를 사용하며 인증정보 생략, 리퍼러 없음, redirect 거절, 5초 abort를 적용합니다. 재시도/응답 파싱/전송 오류 재보고는 없고 기다리지 않습니다. 수집기 부재·예외·오프라인·서버 미배포 상태도 본 기능을 중단하지 않습니다.
- **Slack 토큰/Webhook은 프런트에 절대 넣지 않습니다.** Slack 전달과 자격증명은 백엔드 전담입니다. 백엔드 엔드포인트 및 허용 Origin/CORS 설정이 배포되기 전에는 전달되지 않을 수 있습니다.

### 가입 승인 메일 안내 (v1.3.24)

가입 승인 완료 팝업의 **메일 보내기**는 신청자 이메일을 받는 사람으로 지정하고, 서비스 접속 주소·임시 비밀번호·첫 로그인 후 비밀번호 변경 안내를 담은 `mailto:`를 사용자 클릭 시 생성합니다. 기본 메일 앱에서 내용을 확인하고 직접 전송해야 하며 자동 발송하지 않습니다. 메일 앱 설정이 없으면 열리지 않을 수 있습니다. 팝업은 메일 앱을 열어도 유지되며, 닫으면 비밀번호 입력 요소를 제거합니다. URL을 HTML 링크·저장소·로그에 미리 저장하지 않습니다. 계정 수동 발급·비밀번호 초기화 팝업에는 가입 승인 메일 버튼을 표시하지 않습니다.

v1.3.25부터 **비밀번호 보기**(확인 버튼 색상)와 **메일 보내기**(취소 버튼 색상)는 하단 확인·취소와 같은 간격·크기의 한 줄 버튼으로 표시합니다.

### 출발지 주변 포인트 추천 (v1.7.0)

- 출발지가 없으면 등록을 권하는 말풍선: 등록하면 하루 한 번 가까운 포인트와 오늘 오전·오후 날씨를 먼저 알려 준다고 안내
- 출발지가 있으면 로그인 후 하루 한 번(기기·계정별, KST 날짜 기준) 대화에 주변 추천 카드를 띄운다. 백엔드 `GET /v1/suggest/nearby`(v1.3.21+) 사용
- 반경 10km부터 찾고 없으면 20·30km…(최대 100km)로 넓힌다. 최대 5곳을 안전 판정 → 거리 순으로 1~5순위, 각 포인트에 오늘 오전·오후 하늘·기온·바람·파고 요약
- 카드를 누르면 해당 포인트 상세 안내. 오늘 이미 봤거나 실패하면 기존 오늘의 추천(장기기억)으로 대체
